#  To-Do List

A simple and responsive To-Do List application built with HTML, CSS, and JavaScript. It helps users organize daily tasks and stores data using Local Storage.

##  Features

- Add new tasks
- Set task time
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage

##  Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

##  Future Improvements
- Responsive design
- Clean and modern UI
- Edit task
- Task categories
- Search tasks
- Dark mode
- Drag & Drop tasks
